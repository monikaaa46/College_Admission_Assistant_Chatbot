#  College Admission Assistant Chatbot

A Python-based College Admission Assistant chatbot built with Tkinter to provide quick answers to common college admission queries.

##  Project Overview

The College Admission Assistant is a desktop chatbot application designed to help students get information about college admissions through a simple and user-friendly graphical interface.
The chatbot can respond to queries related to admission procedures, fees, eligibility, courses, documents, scholarships, hostel facilities, placements, deadlines, campus facilities, and other common admission-related topics.

##  Features

- User-friendly Tkinter graphical interface
- Interactive chat-based conversation
- 30+ admission-related topics
- Keyword-based response matching
- Follow-up question suggestions
- Admission information including:
  - Courses
  - Fees
  - Eligibility
  - Admission Process
  - Required Documents
  - Scholarships
  - Hostel
  - Placements
  - Deadlines
  - Entrance Exams
  - Counselling
  - Campus Facilities
  - Library
  - Transport
  - Attendance
  - Internships
- Scrollable chat interface
- Timestamp for messages
- Responsive window layout

##  Technologies Used

- Python
- Tkinter
- Python Standard Library
- GUI Programming
- Keyword-based Natural Language Processing

##  How It Works

The chatbot stores admission-related information in a structured knowledge base containing topics, keywords, and responses.

When the user enters a question:

1. The input is converted to lowercase.
2. The chatbot compares the input with stored keywords.
3. Matching keywords are scored.
4. The topic with the highest score is selected.
5. The corresponding response is displayed.
6. Follow-up questions are suggested to continue the conversation.
